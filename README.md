# NEXORA

Transforme intenção em evolução.

Veja o guia de publicação (sem computador) no chat, ou os passos resumidos abaixo:

1. Crie uma conta em github.com pelo navegador do telemóvel.
2. Crie um repositório novo chamado "nexora".
3. Envie todos estes arquivos para o repositório (opção "Add file" → "Upload files").
4. Crie uma conta em vercel.com com "Continue with GitHub".
5. Clique em "Add New Project", escolha o repositório "nexora" e clique em "Deploy".
6. Aguarde 1–2 minutos. A Vercel entrega um link público (ex: nexora.vercel.app).
7. Para atualizar o site depois, edite os arquivos direto no GitHub — a Vercel publica de novo sozinha.
